# Политика конфиденциальности — Пиксельный календарь

Действует с 18 ноября 2026 года. Приложение «Пиксельный календарь» (Pixel Calendar,
далее — приложение) работает без аккаунтов, аналитики и рекламы.

## Какие данные обрабатываются

- **Дела, серии, напоминания и настройки** хранятся только на вашем устройстве
  (в хранилище приложения). Разработчик к ним доступа не имеет.
- **Экспорт JSON** создаётся по вашему действию и остаётся у вас; файл содержит
  дела в открытом виде.
- **Код подключения к синхронизации** хранится на устройстве открытым текстом и
  нужен только для доступа к вашему серверу в домашней сети.

## Куда уходят данные

1. **Проверка обновлений** — запрос к `api.github.com` за номером последнего
   релиза. Уходит только сам запрос, без данных пользователя и устройства.
   Работает только в APK и отключается в настройках («Проверять обновления»);
   после отключения исходящих запросов у приложения нет вовсе. В браузере
   проверки нет никогда.
2. **Синхронизация** — на адрес сервера, который вы ввели сами (ваш компьютер
   в локальной сети), с вашим кодом подключения. Состояние хранится на вашем
   компьютере в файле сервера синхронизации.
3. **Переходы по нажатию**: «Открыть Google» (текст задачи уходит в
   `calendar.google.com`), «Скачать обновление» (`github.com`), «Поддержать
   проект» (`boosty.to`), «Написать на почту» — в соответствующую службу,
   только когда вы сами нажали кнопку.

Иных исходящих запросов нет.

## Чего приложение не делает

- не собирает аналитику, телеметрию и отчёты о падениях;
- не использует рекламные идентификаторы и не показывает рекламу;
- не создаёт аккаунтов и не продаёт и не передаёт данные третьим лицам;
- не запрашивает данные, не нужные для работы: уведомления и точные будильники
  (напоминания), доступ к сети (проверка обновлений и синхронизация).

Системный автобэкап Android в приложении выключен, поэтому данные не попадают
в облачную копию Google.

## Дети

Приложение не собирает персональные данные и одинаково работает для любых
пользователей.
